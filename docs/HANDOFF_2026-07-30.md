## 新对话处理方式

1. 先读取交接包中的 `prompts/RC_ACCEPTANCE_CODEX_PROMPT.md`。
2. 用户会把该提示词交给 Codex 在 Windows 本机执行。
3. 用户返回 Codex 报告后，只核对证据和结论，不声称能够直接访问其本机。
4. 将结果判定为 PASS、FAIL 或 PASS WITH NOTES。
5. FAIL 时只提出最小阻塞修复，不扩展范围。
6. PASS 时准备正式发布清单，但没有用户明确授权不得创建标签、Release 或上传正式资产。
