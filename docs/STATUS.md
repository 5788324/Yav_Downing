## 已完成

### 资料库

- SQLite 是唯一业务数据源。
- 已支持影片、演员、来源页面、磁链、收藏和手工资料。
- 磁链按 BTIH 去重，同一磁链可以保留多个来源。
- V1 数据可只读迁移到 V2，支持 dry-run 和重复执行。

### 图书馆界面

- 海报墙、收藏架和资料册三种视图。
- 搜索、厂商、系列、演员、来源、收藏和磁链状态筛选。
- 影片详情、资料编辑、收藏、复制磁链和打开来源页。
- 桌面和窄屏布局。

### 来源扫描

- JavDB：全量扫描、继续、停止、进度和磁链写入。
- JPHOO：统一 Edge Profile、登录恢复、扫描、停止、继续和重启恢复。
- 扫描中退出会先停止扫描，再释放浏览器和 Profile。
- JPHOO 停止后最终状态正确为 `stopped`，不会误报 `failed`。

### 数据安全

- 本地备份：数据库快照、本地封面和 manifest。
- 安全恢复：校验、dry-run、恢复前自动备份和失败保护。
- 运行中的 Yav 会拒绝恢复。
- 浏览器 Profile、Cookie 和运行令牌不进入备份。

### Windows 发布包

- 单文件 `Yav-V2.exe`。
- 支持启动、备份、恢复、V1 迁移和安全退出。
- 页面按钮和 `--shutdown` 使用同一正常退出流程。
- 服务只监听 `127.0.0.1`。
- RC4 已完成本机隔离启动、关闭、重启、备份、恢复、迁移和真实 JPHOO 扫描验收。

## 当前只做两件事

### 1. 修稳同时启动

当前单实例机制已经能处理普通重复启动，但锁文件不是完整的进程生命周期锁。极端情况下，两次几乎同时启动可能发生竞争。

本轮将改为整个进程运行期间持续持有的操作系统锁，并增加真实并行启动测试。

### 2. 新 Windows 用户验收

在同一台电脑新建一个 Windows 本地用户，只复制发布包，不安装 Python，不复制源码，验证：

- 空库启动；
- 页面和 API；
- 第二次启动不会产生第二个服务；
- 安全退出和重启；
- 系统 Edge 可以被 JPHOO 会话启动。

## 发布路线

```text
RC4 基线
→ 单实例生命周期锁
→ RC5 构建与并行启动验收
→ 新 Windows 用户验收
→ 合并 main
→ 构建正式 2.0.0
→ 创建 v2.0.0 标签
```

## 明确不做

发布前不再增加：

- 新资源站；
- 下载器或播放器；
- 云同步；
- 用户和权限系统；
- 复杂安全框架；
- 大规模 UI 重做；
- 与本地影片磁链资料库无关的功能。

## 发布判断

当前判断：**本机 RC4 验收通过，尚未正式发布。**

完成单实例并行启动修复和新 Windows 用户验收后，即可进入正式发布流程。
