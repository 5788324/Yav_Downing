## 2026-07-29：本机资料库空白修复（未发布）

- 资料库 SQLite 并非空库：只读核对为 1,517 部影片、1,517 个来源页、11,832 条磁链。
- 空白根因有两层：浏览器保留旧的 8768 地址，而手动启动的开发服务默认使用 8765；更关键的是来源操作 URL 模板在编辑时损坏为无效正则，导致 `app.js` 整体无法执行。
- 修复后以 8768 重启当前验收分支服务；真实浏览器复验首页显示 36 张影片卡片，统计与 API 均为 1,517 部。
- 本轮只修复前端脚本和测试；未扫描、迁移、删除或手改 V1/V2 影片数据。Python 60 项、Node 2 项、前端语法及 diff 检查通过。
