## 图书馆 UI

当前界面支持：

- 海报墙、收藏架、资料册三种结构视图；不是换色主题。
- 影片名搜索。
- 厂商、系列、女演员、来源、磁链状态组合筛选。
- 未知厂商、未分类系列、未知女演员筛选入口。
- 收藏切换和收藏筛选。
- 分页及每页 24/36/48/72 部选择。
- 影片详情、手动资料编辑和手动字段保护。
- 磁链按大小排序，同一 BTIH 展示多个来源。
- 复制磁链和打开来源网页。
- 本地封面、远程封面和无封面占位显示。
- 桌面与窄屏响应式布局。

## 2026-07-26：JPHOO 反复登录修复

- 根因已修复：旧版登录窗口和扫描器分别创建浏览器上下文，且关闭窗口后错误标记为 `ready`；隐藏密码框也会造成误判。
- 现在所有 JPHOO 操作统一使用 `%LOCALAPPDATA%\Yav\v2\browser-profile\jphoo`、同一专用线程和同一 persistent context。关闭浏览器后状态为 `closed / unknown`，不会伪造已登录。
- 登录入口必须选择保存的 JPHOO 系列，浏览器进入该系列实际域名；“完成登录”改为“验证登录”，不会关闭浏览器。
- 诊断只返回域名 Cookie 数量、本地/会话存储键数量、可见/隐藏密码框数量和状态信号，不记录 Cookie、令牌或存储值。
- 真实临时副本验证：打开 `ready`、验证 `ready`、关闭 `unknown`、新会话重开仍为 `ready`；认证来自 6 个本地存储键，未见密码框。

已知限制：JPHOO 站点主动使认证失效时仍需用户在统一 Profile 中手动登录一次；本轮不会绕过站点认证或增加激进重试。

## 2026-07-26：JPHOO 扫描中退出补充修复

- 扫描中点击“关闭会话”会自动请求停止、保存 `stopping`，扫描安全退出后由原专用线程关闭 Edge context；不再把关闭命令排在扫描之后被动等待。
- 应用 `shutdown()` 使用相同链路，并等待工作线程实际结束后再返回，确保 Profile 锁释放；扫描尚未真正启动时也会取消排队扫描并关闭会话。
- 登录状态不再因任意 Cookie/localStorage 直接显示 `ready`：除非检测到受保护的用户菜单或认证命名存储标记，否则保持 `unknown`。
- 新增隔离回归：扫描中 close、扫描中 shutdown、线程结束、browser closed、scanner 清空和数据库 `stopping` 状态；全套 30 项测试通过。
