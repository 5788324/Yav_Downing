## 图书馆 UI

当前界面支持：

- 海报墙、收藏架、资料册三种结构视图；不是换色主题。
- 影片名搜索。
- 厂商、系列、女演员、来源、磁链状态组合筛选。
- 未知厂商、未分类系列、未知女演员筛选入口。
- 收藏切换和收藏筛选。
- 分页及每页 24/36/48/72 部选择。
- 影片详情、手动资料编辑和手动字段保护。
- 磁链按大小排序，同一 BTIH 展示多个来源。
- 复制磁链和打开来源网页。
- 本地封面、远程封面和无封面占位显示。
- 桌面与窄屏响应式布局。

## 当前接口

- `GET /api/movies`
- `GET /api/movies/{id}`
- `GET /api/movies/{id}/cover`
- `GET /api/filters`
- `PATCH /api/movies/{id}`
- `POST /api/movies/{id}/favorite`
