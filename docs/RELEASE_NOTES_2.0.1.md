# Yav 2.0.1

Yav 2.0.1 是针对 2.0.0 UI 全链路审计结果发布的修复版本，不改变数据库结构、扫描规则或数据目录。

## 功能修复

- 修复来源新增、编辑、启用、停用、删除和扫描操作完成后，来源管理界面不立即刷新的问题。
- 修复来源表单中的“取消编辑”按钮无法生效的问题。

## 可用性修复

- 为每页数量、搜索框、来源管理、快速导航和动态来源输入框补充明确的可访问名称。
- 将影片卡片的读屏名称收敛为“打开《片名》详情”。
- 提升键盘提示和详情磁链区的文字、哈希及复制按钮对比度。
- 规范详情与来源管理弹窗的对话框语义。

## 验收

- 83 张影片卡片逐张打开详情。
- 83 个收藏按钮逐个切换并还原。
- 搜索、全部筛选、三种视图、四种每页数量和全部分页控件。
- 影片详情、磁链复制、来源链接、七项影片编辑输入和空状态。
- 来源 CRUD、JavDB/JPHOO 扫描按钮和 JPHOO 会话按钮。
- 桌面、平板、手机布局。
- 页面与 CLI 安全退出。
- 62 个 UI 覆盖项目全部通过。
- 4 个 axe 检查状态均为 0 违规。
- Windows 与 Linux 完整单元测试通过。
- Windows PyInstaller 构建、补丁资源装包、启动和退出冒烟通过。

完整报告见 `docs/UI_AUDIT_2.0.0.md`。
