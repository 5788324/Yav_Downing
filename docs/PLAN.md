# Yav V2 开发计划

更新时间：2026-07-27

## 项目目标

Yav V2 是一个简单、可靠的本地影片磁链资料库：

- 从 JavDB 和 JPHOO 收集影片与磁链；
- 将同一影片的多个来源归并；
- 支持搜索、筛选、收藏、编辑和复制磁链；
- 数据保存在本机 SQLite；
- 不包含下载器、播放器、账号系统或云服务。

## 当前阶段

## 当前执行：RC5

### 目标

解决两次几乎同时启动 Yav 时的单实例竞争窗口。

### 工作项

- [ ] 将单实例哨兵文件改为进程生命周期内持续持有的操作系统锁。
- [ ] 第二个启动器不得删除第一个正在启动实例的 runtime 文件。
- [ ] 增加“服务尚未就绪时第二次启动”测试。
- [ ] 增加两个真实子进程并行启动测试。
- [ ] 确认最终只有一个监听服务。
- [ ] 回归页面退出、CLI 退出、备份、恢复、迁移和 JPHOO 停止状态。
- [ ] 版本更新为 `2.0.0-rc5`。
- [ ] 构建新的 RC5 发布包并记录 SHA-256。

### 完成条件

```text
两个启动器同时运行
→ 只有一个实例取得锁
→ 只有一个服务监听
→ 第二实例正常退出或打开已有页面
→ 不覆盖 runtime
→ 安全退出后端口、进程和锁全部释放
```

## RC5 后的最终验收

在同一台电脑新建一个 Windows 本地用户：

- [ ] 不安装 Python。
- [ ] 不复制源码。
- [ ] 只复制 RC5 发布目录。
- [ ] 空库启动成功。
- [ ] 页面和 API 正常。
- [ ] 第二次启动不产生第二个服务。
- [ ] 页面安全退出和再次启动正常。
- [ ] JPHOO 专用 Edge 会话可以启动。

真实 JPHOO 账号登录和扫描已经使用隔离 Profile 完成，不需要在新用户下重复账号操作。
