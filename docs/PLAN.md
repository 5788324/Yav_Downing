# Yav V2 开发计划

## 项目目标

重做为一个简单的个人影片磁链图书馆：从 JavDB、JPHOO 和未来来源收集影片及磁链，按影片名归并，多来源互补封面和基础资料，并支持按厂商、系列、女演员筛选浏览。

## 阶段 0：冻结旧版

状态：已完成

- [x] 创建 `v1-frozen` 分支，保留旧版基线
- [x] 创建 `v2-rebuild` 分支
- [x] 更新 V2 项目定位和文档
- [x] 在用户本机建立 `v2-rebuild` worktree
- [ ] 备份旧 `library.db`、封面、配置、CSV 和 Excel

## 明确不做

- 下载器或播放器
- 用户和权限系统
- 云同步
- 评分、推荐和复杂标签
- 复杂任务中心
- 企业级插件框架
- 与影片磁链图书馆无关的功能

## 2026-07-26：JPHOO 会话持久化修复

- [x] 登录、验证与扫描统一为一个应用级 Profile、一个 Playwright persistent context 和一个专用线程。
- [x] 登录目标只允许选择已保存的 JPHOO 系列网址；不再导航到固定首页或任意地址。
- [x] 登录诊断只保存数量和可见页面信号；隐藏密码框不会被误判为登录失效。
- [x] 旧系列 `profile_dir` 仅作为历史字段显示提示，不再参与浏览器 Profile 选择。
- [x] 临时副本完成打开、验证、关闭、重启会话恢复验收。
- [x] 扫描中关闭或应用退出会先安全停止扫描，再由会话线程释放 Edge/Profile。
- [x] 登录 ready 需要受保护认证标记，普通 Cookie 或主题存储仅显示 unknown。
