# Yav V2 开发计划

更新时间：2026-07-27

## 项目目标

Yav V2 是一个简单、可靠的本地影片磁链资料库：

- 从 JavDB 和 JPHOO 收集影片与磁链；
- 将同一影片的多个来源归并；
- 支持搜索、筛选、收藏、编辑和复制磁链；
- 数据保存在本机 SQLite；
- 不包含下载器、播放器、账号系统或云服务。

## 当前阶段

当前处于 **发布收尾阶段**。

功能开发已经完成。发布前只剩：

1. 本机 RC5 完整回归和构建；
2. 新 Windows 用户环境验收；
3. 正式发布。

解决两次几乎同时启动 Yav 时的单实例竞争窗口。

- [x] 将单实例哨兵文件改为进程生命周期内持续持有的操作系统锁。
- [x] 第二个启动器不能删除第一个正在启动实例的 runtime 文件。
- [x] 第二个启动器会等待首个实例启动并读取其实际端口。
- [x] 释放时按 instance ID 清理，不会删除其他实例状态。
- [x] 增加“服务尚未就绪时第二次取得锁失败”测试。
- [x] 增加两个真实子进程并行竞争测试。
- [x] 版本更新为 `2.0.0-rc5`。
- [x] 新增 4 项锁测试并在隔离环境通过。

### 待本机完成

- [ ] 构建新的 RC5 发布包并记录文件大小和 SHA-256。
- [ ] 同时启动两个 RC5 EXE，确认最终只有一个监听服务。

### 完成条件

```text
两个启动器同时运行
→ 只有一个实例取得锁
→ 只有一个服务监听
→ 第二实例正常退出或打开已有页面
→ 不覆盖 runtime
→ 安全退出后端口、进程和凭据全部释放
```

- 下载器或播放器；
- 用户和权限系统；
- 云同步；
- 评分、推荐和复杂标签；
- 复杂任务中心；
- 企业级插件框架；
- 额外安全平台或网络服务。
