## 审计发现并修复的问题

1. 每页数量下拉框缺少可访问名称。
2. 搜索键盘提示文字对比度不足。
3. 影片卡片按钮的读屏名称包含整张卡片的冗余内容。
4. 详情磁链区的说明文字、哈希和复制按钮对比度不足。
5. 弹窗容器语义不够规范。
6. 来源新增、编辑、启停、删除和扫描操作完成后不立即刷新。
7. 来源表单的“取消编辑”按钮无法生效。
8. 动态来源表单文本框缺少明确可访问名称。

## 测试边界

- 影片、收藏、编辑、筛选、分页和安全退出使用真实本地 API。
- 来源 CRUD、登录和扫描 API 使用确定性浏览器路由模拟，以验证全部 UI 状态而不访问外部资源站或修改真实 Profile。
- JPHOO 真实 Edge、登录和扫描链路由 2.0.0 发布前的打包验收覆盖。
