# Yav V2 工作日志

## 2026-07-26：启动 V2 重构

### 完成

- 分析 V1 项目结构和现有抓取链路。
- 确认旧 Tkinter 小工具不再继续扩建，V2 将重做 UI 和代码结构。
- 将项目范围收缩为个人影片磁链图书馆。
- 确认磁链是核心数据，影片资料只用于识别、浏览和筛选。
- 确认多来源按影片名归并并互补资料。
- 确认图书馆支持按厂商、系列和女演员筛选。
- 创建远端 `v1-frozen` 分支。
- 创建远端 `v2-rebuild` 分支。
- 更新 V2 README、开发约束、开发计划和当前状态。

### 决定

- 每部影片只保存影片名、封面、厂商、系列、女演员、日期、时长、收藏和各来源磁链。
- 资料允许缺失，不要求任何单一资源站提供完整数据。
- 普通资料补空不覆盖；女演员合并去重。
- 磁链按 BTIH 去重并追加保存，不覆盖旧磁链。
- SQLite 是唯一业务数据源。
- 不引入用户系统、权限系统、下载器、播放器或复杂任务平台。

## 2026-07-26：完成阶段 0 与阶段 1 最小骨架
